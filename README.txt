War Thunder Datamine — Автономное приложение
=============================================
ЭТО ПОЛНОЦЕННОЕ ПРИЛОЖЕНИЕ, НЕ САЙТ. Работает без localhost, без Python, без сервера.

Как запустить:
1. Распакуй архив куда угодно
2. Двойной клик по WarThunder_Datamine_App.html — откроется в браузере как программа
3. Выбери Версия A (старая) и Версия B (новая) -> нажми "Сравнить A → B"
4. Слева увидишь что добавилось / изменилось / удалилось, справа — как именно (diff / картинка)

Авто-скачка новых версий:
- Галочка "Авто-скачка новых версий" включена — каждые 60с проверяет GitHub gszabi99
- Если появится новая версия (например 2.59.0.17) — покажет уведомление и добавит в список
- Можешь вручную нажать ↻ чтобы обновить список

Не требует установки, не требует интернета кроме загрузки списка версий с GitHub.
Если лимит GitHub 60 запросов/час — нажми 🔑 и введи токен (github.com/settings/tokens).

Можно установить как приложение:
- В Chrome нажми ⋮ -> "Установить приложение" или "Добавить на главный экран" (телефон)
- Тогда будет иконка как у программы

Для локального майнинга своей папки War Thunder используй wt_mine.py (нужен Python)
