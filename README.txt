War Thunder Datamine — Автономное приложение
=============================================
ЭТО ПОЛНОЦЕННОЕ ПРИЛОЖЕНИЕ, НЕ САЙТ. Работает без localhost, без Python, без сервера.

Как запустить:
1. Распакуй архив куда угодно
2. Двойной клик по WarThunder_Datamine_App.html — откроется в браузере как программа
3. Выбери Версия A (старая) и Версия B (новая) -> нажми "Сравнить A → B"
4. Приложение САМО сформирует готовый отчёт — откроется вкладка "📊 Отчёт"

🤖 Авто-отчёт (готовый отчёт об изменениях):
- После сравнения приложение само понимает, что изменилось, и открывает вкладку "📊 Отчёт"
- В отчёте: статистика (+добавлено / ~изменено / -удалено), блок "⭐ Главное"
  (новые юниты с их ТТХ, удалённые юниты, крупнейшие баффы/нерфы)
- Каждый изменённый .blk разобран по параметрам: "лобовое сопротивление (Cx):
  0.0211 → 0.0250 (+18.5%) • нерф" — с пометкой бафф/нерф и вердиктом по файлу
- Файлы сгруппированы по категориям: ✈️ лётные модели, 🛩️ авиация, 🪖 наземная
  техника, ⚓ флот, 💥 вооружение, 🎨 текстуры/скины, 🖥️ интерфейс и т.д.
- В превью любого файла есть авто-сводка одной строкой (🤖 Авто-анализ: нерф • ...)
- Из отчёта можно: скопировать текст, скачать .md, скачать standalone .html, распечатать
- Кнопка "📊 Авто-отчёт" в левом меню и иконка 📊 в шапке превью — вернуться к отчёту

Авто-скачка новых версий:
- Галочка "Авто-скачка новых версий" включена — каждые 60с проверяет GitHub gszabi99
- Если появится новая версия (например 2.59.0.17) — покажет уведомление и добавит в список
- Можешь вручную нажать ↻ чтобы обновить список версий

Не требует установки, не требует интернета кроме загрузки списка версий с GitHub.
Если лимит GitHub 60 запросов/час — нажми 🔑 и введи токен (github.com/settings/tokens).

Можно установить как приложение:
- В Chrome нажми ⋮ -> "Установить приложение" или "Добавить на главный экран" (телефон)
- Тогда будет иконка как у программы

Для локального майнинга своей папки War Thunder используй wt_mine.py (нужен Python).
Он тоже сам собирает готовый отчёт (включая 🗒️ Changelog; список затронутых
самолётов по изменённой броне находится локальным сканом дампа):
  python wt_mine.py --compare ./dump_2.58 ./dump_2.59                      # отчёт в консоль
  python wt_mine.py --compare ./dump_2.58 ./dump_2.59 --md report.md --html report.html
  python wt_mine.py --compare ./dump_2.58 ./dump_2.59 --json diff.json     # сырой diff как раньше
